# Aftergrove (web playtest)

A small original idle game. Chop trees, buy hatchets and auto-choppers, and keep going after you close the tab.

This repository hosts the Godot 4 HTML5 export so you can play it in a browser.

**Play:** https://dlicarus1914.github.io/aftergrove-test/

Progress is saved in your browser (localStorage). Clearing site data resets the grove. The first load downloads about 38 MB (the engine `.wasm`).
